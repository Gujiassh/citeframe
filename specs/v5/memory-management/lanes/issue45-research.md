## 4. Composition and every-dispatch algorithm

Proposed #45-local `apps/worker/src/ai_pdf_worker/research/adapters/memory.py` owns ResearchMemorySession, an application adapter binding native policy/lease to shared gate/archive/journal. `research/memory_context.py` owns deterministic role/journal projection and restoration. `research/persistence.py` supplies injected sessions/storage/connection/counter and transaction-neutral native callbacks. No new API-route/provider-factory import; consume neutral adapters directly with configuration from existing bootstrap. Missing/unsupported profile fails before dispatch.

1. Resolve actual Step/Attempt, frozen role/prompt/IO/context release and native plan/execution owner. ContextOwner(kind=research, owner_id=Attempt.id, actor=run creator, workspace, server-derived existing lease hash). Never invent lease_generation, trust model identity or log credentials.
2. Load committed pointer and native journal frontier under current guards. Assemble original units plus protected system/current goal/schema/evidence constraints and task status. Native typed-batch encoding remains lossless final projection; its old rejecting packer must not run before semantic compaction can reduce history.
3. Freeze exact input/source/native-journal manifest and stable role/operation/turn/continuation identity. Gate every actual initial/continuation/role/resume call. Required current claim/evidence/schema material cannot be dropped for capacity.
4. Gate may perform bounded nonrecursive summaries and atomic adoption. Send its exact returned request; no second reservation via legacy _generate and no post-count payload-changing reserialization. Native capability matcher remains required, without permissive fallback.
5. authorize_send verifies request hash/current sources/cancel/lease. Invoke GenerationPort under heartbeat spanning main and summary IO. No DB guard across network. Require complete provider batch/terminal before tool execution or final role JSON acceptance.
6. Genuine memory-tool turn: validate args/policy, reserve complete batch allowance, execute bounded reads, persist original results/dependencies, then gate again without user input. Only final answer enters existing role validators. Partial text/JSON before tools is not role completion.
7. Settle via CallJournal's native callback once. Store validated result in its original adaptive/conflict/completion journal under native rules. Compaction never completes the business step. Lost source/lease/cancel/context after remote return permits accounting-only settlement, not body adoption.

Stable key derives from Attempt + node + native operation/turn + continuation ordinal + frozen input fingerprint. Resume uses the same key; genuine native retry has its new native identity with prior spent/unknown usage retained. Checkpoint advancement does not reset ordinal. Recover durable results by exact key/hash before send. Existing bounded limits remain immutable operational configuration. Error mapping: context_limit_exceeded→research_context_limit_exceeded; source/context mismatch→research_memory_context_invalid; unknown remote result retains native outcome_unknown. The native failure classifier must not automatically requeue these unchanged conditions; actual permission loss/cancel retains native terminal handling. Role completion still validates original claim/evidence invariants after the gate.
